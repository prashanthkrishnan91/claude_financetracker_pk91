# Do Not Build Yet — Finance

Things that are explicitly out of scope until upstream work lands. This is the scope-creep firewall.

- Auto-trading.
- Broker execution.
- LLM / agent / research final visible decisions.
- Raw metric-heavy UI (no diagnostics, shadow labels, posture labels in visible UI).
- Full design sprint before Deploy / Watchtower loop is stable.
- Overly complex research-agent UI before deterministic value is clear.

If an idea matches one of these, it goes to `docs/product/IDEA_INBOX.md`, not the build queue.
